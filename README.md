# CaveScrape — map

**Password-protected** landing page + interactive overview map for **CaveScrape**, a LiDAR-based
cave-lead finder for Vancouver Island karst.

🔒 **Live (password required):** https://jed-cmd.github.io/cavescrape-map/

The pages are client-side encrypted with [StatiCrypt](https://github.com/robinmoisson/staticrypt) —
enter the password to decrypt in-browser. This repo holds only the coarse, public-data overview
(karst *regions*, no cave entrances). The detector and its outputs live in a separate private repo.

Built on free BC open data (Reconnaissance Karst Potential Mapping, LidarBC).
